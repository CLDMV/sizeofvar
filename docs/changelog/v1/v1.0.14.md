# sizeofvar v1.0.14 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

A dev-dependency patch. `vitest` and `@vitest/coverage-v8` move from 5.0.2 to 5.0.3 in the lockfile. `sizeofvar.js` is exactly as in v1.0.13, and `package.json` differs only in its `version` field: the `^5.0.0` ranges already allowed 5.0.3, so no range changed. Every package that changed in `package-lock.json` is a development dependency, and the package still has no runtime dependencies.

Nothing about the Node.js requirements changes. `@cldmv/vitest-runner` was already at 1.5.3 in v1.0.13 (with its `>=22.12.0` floor and `chalk` 6), the new `vitest` release keeps the same `^22.12.0 || ^24.0.0 || >=26.0.0` engines, and the CI matrix starts at 22.12.0. The package declares no `engines` field, and that is unchanged.

---

## 🔧 CI & tooling

- This repository's `build` and `build:ci` scripts are `echo` placeholders, because there is nothing to compile: the package ships `sizeofvar.js` as written. A passing `build:ci` therefore proves nothing about this release. The verification that counts is the test suite, and `npm test` passes on the merged `next` branch (7 files, 91 tests).

## 🔧 Dependencies

All development-only; lockfile changes only.

- `vitest` 5.0.2 → 5.0.3 ([#39](https://github.com/CLDMV/sizeofvar/pull/39)), with `@vitest/mocker` and `@vitest/spy` at 5.0.3. `vitest` 5.0.3 pins `why-is-node-running` to exactly 3.2.1, so that package resolves one patch version lower than before (3.2.2 → 3.2.1).
- `@vitest/coverage-v8` 5.0.2 → 5.0.3 ([#40](https://github.com/CLDMV/sizeofvar/pull/40)).
- Transitive tooling that moved with the Vitest update: `vite` 8.3.1 → 8.3.2, `rolldown` 1.2.11 → 1.2.12 (and its platform bindings) and `@oxc-project/types` 0.151.0 → 0.152.0.
