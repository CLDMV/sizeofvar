# sizeofvar v1.1.1 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `release/1.1.1`

---

## Overview

v1.1.0 set `engines.node` to `>=22.22.0`. That is the floor of the build and test toolchain, not something sizeofvar needs to run. This release sets `engines.node` to `>=16.0.0` and records the toolchain floor separately in npm's `devEngines`, so projects on older Node.js releases can install v1.1.x without an `EBADENGINE` warning.

The size heuristic is unchanged: every value returns the same byte count as in v1.1.0. The CommonJS entry's error message and the build target are the only other changes to what ships.

---

## 🐛 Bug Fixes

### `engines.node` describes the runtime ([#64](https://github.com/CLDMV/sizeofvar/pull/64))

- `engines.node` is `>=16.0.0` instead of `>=22.22.0`. The package has no dependencies, so this is the floor for `import` of the ESM build.
- The tsup build targets `node16` instead of `node20`, so `dist/index.mjs` contains no syntax newer than that floor.
- The CommonJS entry's `ERR_REQUIRE_ESM` message now says `require()` needs Node.js ^20.19.0 or >=22.13.0 (the versions with `require(esm)`), instead of >=22.22.0. A new `node --test` case checks that message by running `dist/index.cjs` with `require(esm)` turned off.

---

## 📦 Requirements

- **Runtime:** Node.js `>=16.0.0` (`engines.node`) for `import`. `require()` needs Node.js ^20.19.0 or >=22.13.0; on older versions, load the package with `import()`.
- **Development:** Node.js 22.22.0 or later, declared in the new `devEngines.runtime` field (`onFail: "error"`), so npm stops with an error when it is run in a checkout on an older Node.js.

---

## 🔧 CI & tooling

- The `min_node_version` input descriptions and a comment in `ci.yml` and `publish.yml` now say the 22.22.0 matrix floor is the dev toolchain floor and should match `devEngines`, not `engines` ([#64](https://github.com/CLDMV/sizeofvar/pull/64)). The matrix itself still starts at 22.22.0.

## Upgrade notes

- No breaking changes. Anyone who stayed on v1.0.14 because of v1.1.0's Node.js 22.22.0 requirement can upgrade on Node.js 16 or later with `import`, or on ^20.19.0 / >=22.13.0 with `require()`.
- The deep import `@cldmv/sizeofvar/sizeofvar.js` that v1.1.0 removed stays removed; import `@cldmv/sizeofvar`.
