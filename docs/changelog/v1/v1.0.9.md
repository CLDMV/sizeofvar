# sizeofvar v1.0.9 Changelog

**Release Date**: September 2026
**Release Type**: Patch

---

## Overview

Moves the test toolchain to vitest 5 and updates the CI node matrix and signing secrets to match. No runtime code changed.

---

## 🔧 Dependencies

### vitest 5 ([#15](https://github.com/CLDMV/sizeofvar/pull/15))

`vitest` and `@vitest/coverage-v8` move from `^4.1.10` to `^5.0.0` in `package.json`. Both are dev dependencies and affect only the test/CI toolchain. The lockfile also refreshes transitive packages (`rolldown`, `@oxc-project/types`).

## 🔧 CI & tooling

### Node CI matrix for vitest 5 ([#17](https://github.com/CLDMV/sizeofvar/pull/17))

`ci.yml` / `publish.yml` defaults: `min_node_version` 20 → `22.12.0` (vitest 5's real floor) and `max_node_major` 22 → `26`. `dependabot.yml` gains groups that keep `vitest` + `@vitest/*` (and the eslint and prettier families) bumping together.

## 🔒 Security & supply chain

### hotfix-redirector GPG secrets ([#13](https://github.com/CLDMV/sizeofvar/pull/13))

`hotfix-redirector.yml` maps `BOT_NAME`, `BOT_EMAIL`, `BOT_GPG_PRIVATE_KEY` and `BOT_GPG_PASSPHRASE` so Dependabot security PRs redirected away from `master` are cherry-picked as signed commits.
