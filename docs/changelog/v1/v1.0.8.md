## Overview

Dev-dependency lockfile refresh plus a bot-identity CI fix. No runtime code changed.

## 🔧 CI & tooling

### Bot identity secrets ([#11](https://github.com/CLDMV/sizeofvar/pull/11))

`feature-pr.yml`, `next-release.yml` and `hotfixes-release.yml` pass `BOT_NAME` and `BOT_EMAIL` (from `CLDMV_BOT_NAME` / `CLDMV_BOT_EMAIL`) so bot-authored commits and PRs use the real bot identity.

## 🔧 Dependencies

### Patch group bump ([#10](https://github.com/CLDMV/sizeofvar/pull/10))

Lockfile-only update of the vitest toolchain's transitive packages (for example `rolldown` and `@oxc-project/types`). `package.json` ranges did not change. These are dev dependencies and only affect the test/CI toolchain.
