# sizeofvar v1.0.7 Changelog

**Release Date**: August 2026
**Release Type**: Patch

---

## Overview

CI-only release. The CI concurrency rules are changed so release-relevant runs are never cancelled. No runtime code changed.

---

## 🔧 CI & tooling

### Never supersede release-relevant CI runs ([#8](https://github.com/CLDMV/sizeofvar/pull/8))

`ci.yml` concurrency now gives pushes to the release base branch, to `next`/`hotfixes`, and the `next`/`hotfixes` release PRs a unique concurrency group per run; feature branches still cancel superseded runs. Previously a burst of pushes during a release could cancel a pending run and leave a red cancelled check on the release PR.
